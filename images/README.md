# Images for GitHub Repository

This folder should contain screenshots from your research paper.

## Required Images

Please add the following images from your research paper:

| Filename | Description | Paper Figure |
|----------|-------------|--------------|
| `modbussim_config.png` | ModBus_SIM Ethernet TCP/IP Settings | Figure 1 |
| `normal_off_state.png` | Normal OFF state (coils = 0x0000) | Figure 3(a) |
| `normal_on_state.png` | Normal ON state (coils = 0xFFFF) | Figure 3(b) |
| `active_attack.png` | Active attack showing coils forced ON | Figure 4(a) |
| `post_attack.png` | Post-attack system state | Figure 4(b) |
| `wireshark_capture.png` | Wireshark showing plaintext Modbus traffic | Figure 5 |
| `attack_sequence.png` | Sequence diagram of 4-phase attack | Figure 2 |
| `defense_architecture.png` | Defense-in-depth architecture | Figure 6 |

## How to Add Images

1. Take screenshots from your research paper PDF
2. Save as PNG files with the names above
3. Place in this `images/` folder
4. Commit and push to GitHub

## Image Size Recommendations

- Width: 800-1200 pixels
- Format: PNG (preferred) or JPG
- Clear and readable text
